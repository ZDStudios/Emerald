Before you run it

  • The builds are unsigned. macOS refuses to open the app on first launch — right-click it and choose Open, or run xattr -dr com.apple.quarantine /Applications/Emerald.app. Windows SmartScreen warns; More info → Run anyway. Signing certificates cost money this project does not have.
  • Windows installs per-user. Into %LOCALAPPDATA%, so there is no administrator prompt. The .msi is there if you need a machine-wide install instead.
  • The .deb also installs the reading typefaces system-wide, so the dyslexia font applies to web page text. The AppImage and the other platforms' packages do not.
  • The .app.tar.gz files are not for you. They are updater bundles, and Emerald does not use them — take the .dmg.
  • Emerald checks for updates itself once per window, and offers to fetch the new installer. One switch in Settings → Privacy turns it off.
