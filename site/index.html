A browser that gets out of the way.

Emerald ships no rendering engine — it uses the one your operating system already has. Nothing autoplays, nothing flashes, nothing reorders itself, and the tab you forgot about on Tuesday gets its memory taken back.

What it is

A native shell around the engine you already have.

Chrome, Edge, Arc, Brave and Opera all ship the same engine, and each ships its own copy. Emerald ships none. On macOS and Linux it renders with WebKit; the download is about six megabytes, and the engine's code is already in memory, shared with every other app using it.

That is the whole trick, and it has a price. Here is the price.

On Windows there is no non-Chromium webview to build on, so Emerald renders with Chromium there. Saying otherwise would be marketing. Everything else — the tab policy, the accessibility layer, the settings model — is identical on all three.

Focus & Access

Built for brains that don't work the default way.

Not an accessibility panel bolted onto a browser. 69 settings, grouped by what they are actually for, reachable from anywhere with one keystroke — and most of the useful ones are on by default, because a calm baseline should not be something you have to go and find.

Attention

Fewer things asking for a response.

  • A hard ceiling on how many tabs stay awake
  • Idle tabs archived, never deleted
  • Focus mode: dim everything, or one thing at a time
  • Animation speed down to zero
Predictability

Nothing moves without being asked.

  • Autoplay blocked before the page's own scripts run
  • Scroll anchoring, so late banners don't push your line
  • Tabs never reorder themselves
  • Muted and high-contrast colour profiles
Reading

Typography you can actually change.

  • OpenDyslexic and Atkinson Hyperlegible built in
  • Letter, word, line and paragraph spacing past the WCAG floors
  • A reading ruler that follows pointer or keyboard
  • Measure limiting, on any page
Input

Nothing you typed is ever lost.

  • Every web form field autosaved locally as you type
  • Passwords and card numbers deliberately excluded
  • 44px minimum hit targets without reflowing the page
  • Enter-to-submit guard for half-written forms

Make it yours

Or make it look like the browser you already use.

Emerald's default is a vertical sidebar, because a horizontal strip turns into a row of indistinguishable favicons exactly when you have enough tabs to need to tell them apart. But a familiar shape costs nothing to learn, and making someone relearn tab management on day one is its own barrier — so the Chrome-shaped layout is one click, not a fork.

Four Catppuccin flavours, seven accents, three densities, and colour profiles that change how loud things are without ever changing what a colour means.

And here's where it loses

Emerald's cost per additional awake tab is about 24 MB. Chromium's is about 11. It wins on the floor, not the slope — what keeps the totals down at twenty tabs is the discard policy, not per-tab efficiency.

Startup is 1.3 seconds

The Rust core is ready in 27 ms. The remaining second is the interface loading, and it has not been optimised or even properly attributed yet. That is slower than it should be.

One machine, one platform

Linux, software rendering, a browser that has been open for ten seconds. Not macOS, not Windows, not a six-hour session with a warm cache.

Why say any of that

Because a benchmark that only lists its wins is an advertisement, and you cannot check an advertisement. The harness, the fixture pages and the raw JSON are all in the repository. Run it yourself:

CHROMIUM=/path/to/chrome ./bench/run.sh

An earlier version of the benchmark reported a 261 ms startup. It was wrong — the binary had silently failed to load its own interface, so it started fast because there was nothing to start. That correction is still in the docs, because deleting it would be the dishonest move.

Not settings, on purpose

Three things Emerald will not do.

There is no switch for any of these, because there is no code for them.

Nothing phones home.

No telemetry, no crash reporting, no update ping, no account. Even page prefetch is off by default, so Emerald opens the connections you asked for and no others.

Nothing in the interface flashes, blinks, pulses or breathes.

In any theme, at any animation speed, for any reason. This is enforced by a global CSS rule that cancels every looping animation, not by everyone remembering the guideline.

Colour meaning never moves.

Red is destructive, yellow needs attention, the accent means "this is yours". Change the theme or the accent and those stay put, so what you learned on day one is still true on day ninety.

Builds are unsigned. Here's what that means.

macOS will refuse to open the app the first time — right-click it and choose Open. Windows SmartScreen will warn you; choose More info, then Run anyway. Code-signing certificates cost money this project does not have, and telling you now is better than letting you find out.
